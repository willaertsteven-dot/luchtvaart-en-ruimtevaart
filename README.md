# ✈️ Hemel & Ruimte 🚀

Een persoonlijke, Nederlandstalige website over vliegtuigen, luchtvaart, SpaceX en ruimtevaart.

Secties: iconische vliegtuigen, SpaceX (Falcon 9, Falcon Heavy, Starship, Dragon, herbruikbare boosters), een tijdlijn met mijlpalen, een lanceersimulatie met aftelklok en een quiz.

Pure HTML/CSS/JS, geen build-stap. Alle illustraties zijn CSS, SVG of emoji.
